## 0. 한 줄 정의

칼만 필터로 두 자산의 시변 관계 \((\alpha_t, \beta_t)\)를 온라인 추정하고, 한 스텝 예측 오차(innovation)가 통계적으로 벌어지면 스프레드를 페이드한다. 관계가 회귀하면 청산하고, 관계가 깨졌다고 판단되면 손절한다.

거래하는 대상은 개별 코인의 방향이 아니라 **잔차 \(e_t\)** 다.

## 1. 배경과 문제

### 1.1 왜 칼만인가

정적 OLS 또는 고정 윈도우 롤링 회귀는 헤지비율 \(\beta\)를 한 덩어리로 재추정한다. 코인 관계는 천천히 변하므로,

- 창이 길면 \(\beta\)가 늦고
- 창이 짧으면 \(\beta\)가 요동한다.

칼만은 내부적으로 \((\alpha, \beta_{scaled})\)를 숨은 상태로 두고 매 봉 조금만 갱신한다. 외부 로그 헤지비율은 \(\beta_{scaled}/x_{scale}\)로 복원한다. 같은 루프에서 잔차 \(e_t\)와 예측 분산 \(S_t\)가 나와, 별도 롤링 표준편차 없이

\[
z_t = \frac{e_t}{\sqrt{S_t}}
\]

를 신호로 쓴다.

### 1.2 왜 한국 리테일에서 코인 perp인가

국내 현물·주식은 리테일 공매도 제약이 커서 양다리 스프레드를 만들기 어렵다. 실행 가능한 장은 해외 거래소 USDT 무기한이다. 본 스펙은 OKX 한 거래소, USDT 마진만 사용한다. 코인마진(`-USD-SWAP`)과 섞지 않는다.

### 1.3 BTC–ETH의 위치

BTC–ETH는 **벤치마크**다. 유동성과 데이터는 최고이나, 스프레드가 “일시 괴리”가 아니라 ETH/BTC 국면 전환인 경우가 많다. 포트폴리오 전부로 두지 않는다.

더 나은 구조는

1. BTC를 시장 팩터로 둔 잔차 북 (`Y ~ BTC`)
2. 같은 섹터 피어 북 (형성 통과 시에만 On)
3. 같은 자산 베이시스/페그 (본 스펙 범위 밖, 별도 북)

## 2. 모델

### 2.1 상태공간

가격은 **로그 mark** 를 쓴다. last는 체결 기록용이다.

관측:

\[
y_t = \ln P^Y_t, \quad x_t = \ln P^X_t
\]

형성 창에서 \(x_t\)의 다음 값을 한 번 계산하고 거래 창 동안 고정한다.

\[
x_{center} = \operatorname{mean}(x_t), \quad
x_{scale} = \max(\operatorname{population\_std}(x_t), 10^{-6})
\]

\[
u_t = \frac{x_t - x_{center}}{x_{scale}}
\]

내부 상태는 정규화된 상태 \(\boldsymbol{\theta}_t\)를 사용한다.

\[
\boldsymbol{\theta}_t =
\begin{bmatrix} \alpha_t \\ \beta_{scaled,t} \end{bmatrix}, \quad
y_t = \alpha_t + \beta_{scaled,t}u_t + v_t
\]

외부 헤지에 사용하는 로그 헤지비율은 항상 다음처럼 복원한다.

\[
\beta^{log}_t = \frac{\beta_{scaled,t}}{x_{scale}}
\]

정규화 모델은 S01에서 구현한 계약이다. 기존 전략 의도인 잔차 거래와 노셔널 헤지는 유지하되, 필터 내부 상태는 위 정규화 상태를 사용한다.

상태 방정식 (랜덤워크):

\[
\boldsymbol{\theta}_t = \boldsymbol{\theta}_{t-1} + \mathbf{w}_t,
\quad \mathbf{w}_t \sim \mathcal{N}(0, Q)
\]

\[
Q = q I_2, \quad q = R\frac{\delta}{1-\delta}, \quad \delta = 10^{-4}
\]

\(\alpha\)와 \(\beta_{scaled}\)는 같은 로그 Y 가격 단위이므로 같은 상태 잡음 스케일을 사용한다. 관측 잡음은 다음과 같다.

\[
y_t = \alpha_t + \beta_{scaled,t}u_t + v_t, \quad
v_t \sim \mathcal{N}(0, R), \quad R = 10^{-3}
\]

관측행렬은 \(H_t = [1,\ u_t]\)이다.

### 2.2 재귀

매 1시간 봉:

첫 번째 유효 관측에서 lazy initialization 한다. \(\beta_{scaled,0}=1.0\times x_{scale}\), \(\alpha_0=y_0-\beta_{scaled,0}u_0\), \(P_0=\operatorname{diag}(R,R)\)로 시작한다. 이 관측은 유효 업데이트 1회로 세지만 초기화 결과의 혁신과 \(z\)는 0으로 두고 신호로 사용하지 않는다.

초기화 이후 각 유효한 완성 봉에서 다음 순서로 계산한다.

1. 예측: \(\hat{\boldsymbol{\theta}}_{t|t-1} = \hat{\boldsymbol{\theta}}_{t-1}\), \(P_{t|t-1} = P_{t-1} + Q\)
2. 예측 관측: \(\hat y_t = H_t \hat{\boldsymbol{\theta}}_{t|t-1}\)
3. 혁신 분산: \(S_t = H_t P_{t|t-1} H_t^\top + R\)
4. 혁신: \(e_t = y_t - \hat y_t\)
5. 게인: \(K_t = P_{t|t-1} H_t^\top S_t^{-1}\)
6. 수정: \(\hat{\boldsymbol{\theta}}_t = \hat{\boldsymbol{\theta}}_{t|t-1} + K_t e_t\)
7. Joseph form: \(P_t = (I-K_tH_t)P_{t|t-1}(I-K_tH_t)^\top + K_tRK_t^\top\)
8. 갱신 후 \(P_t\)를 대칭화하고 \(S_t\)가 유한하고 양수인지 확인한다.

신호:

\[
z_t = \frac{e_t}{\sqrt{S_t}}
\]

\(e_t\)와 \(z_t\)는 posterior 상태 갱신 전에 계산한 one-step innovation이다.

- \(z > 0\): \(Y\)가 관계 대비 비싸다 → **숏 스프레드** (\(Y\) 매도, \(X\) 매수)
- \(z < 0\): \(Y\)가 싸다 → **롱 스프레드** (\(Y\) 매수, \(X\) 매도)

### 2.3 고정 하이퍼파라미터

| 항목 | 값 | 비고 |
|---|---|---|
| 봉 | 1시간 | |
| 가격 | `markPx` | 신호 |
| 변환 | \(\ln(\text{mark})\) | 레벨 칼만으로 바꾸지 않음 |
| 정규화 | \(x_{center}=\operatorname{mean}(\ln P^X)\), \(x_{scale}=\max(\operatorname{population\_std}(\ln P^X), 10^{-6})\) | 형성 창에서 1회 계산 후 거래 창 동안 고정 |
| \(\delta\) | `0.0001` | Chan 관례. v1.0에서 올리지 않음 |
| \(R\) | `0.001` | |
| 상태 | \(\alpha, \beta_{scaled}\) | \(F = I\), 외부 \(\beta^{log}=\beta_{scaled}/x_{scale}\) |
| \(Q\) | \(qI_2\), \(q=R\delta/(1-\delta)\) | 정규화 상태에 적용 |
| burn-in | **72 유효 업데이트 (3일)** | 1~71번째는 신호 미준비, 72번째부터 `ready`; 잘못된 가격은 카운트하지 않음 |
| 스무더 | 사용 금지 | 필터만. 미래 정보 오염 방지 |

비양수·비유한 가격은 로그 변환 전에 거부하고 상태나 유효 업데이트 카운트를 변경하지 않는다.

### 2.4 헤지 수량

로그 \(\beta\)는 탄력성이다. 헤지는 코인 개수가 아니라 **USDT 노셔널**.

목표 노셔널 \(N\) (USDT)에 대해

\[
Q_Y = \frac{N}{P^Y_t}, \qquad Q_X = \frac{\hat\beta^{\log}_t \cdot N}{P^X_t}
\]

진입 시점의 \(\hat\beta\)를 고정한다. 이후

\[
\frac{\lvert \Delta\beta \rvert}{\lvert \beta_{\text{entry}} \rvert} \ge \text{리헤지 임계}
\]

일 때만 \(X\) 다리를 조정한다. \(Y\)는 유지.

### 6.1 Hard — 하나라도 실패하면 Off

| 단계 | 항목 | Factor | Peer |
|---|---|---|---|
| 유동성 | 24h 거래대금 중앙값 | ≥ $50M | ≥ $20M |
| 유동성 | OI 중앙값 | ≥ $30M | ≥ $12M |
| 유동성 | $10k 반스프레드 | ≤ 3 bp | ≤ 6 bp |

| 비용 | \(2\sigma_e\) vs 왕복비용 | \(2\sigma > 2.5c\) | 동일 |
| 관계 | 로그수익 상관 \(\rho\) | 0.55 ~ 0.92 | 동일 |
| 관계 | 잔차 반감기 HL | 6시간 ~ 10일 | 동일 |
| 관계 | Hurst(잔차) | < 0.48 | 동일 |
| 관계 | ADF p(잔차) | < 0.15 | Hurst>0.55 AND p>0.3 이면 Out |
| 관계 | \(\mathrm{IQR}(\beta)/\lvert\mathrm{med}\,\beta\rvert\) | < 0.40 | 동일 |
| 관계 | \|z\| > 4.5 | ≤ 2회 / 30일 | 동일 |
| 관계 | 한쪽만 급변 | 12h 중 Y ±20% & X ±5% 이내 ≤ 2회 (3회 Out) | 동일 |
| 관계 | \(\lvert\mathrm{corr}(\Delta f, e)\rvert\) | ≤ 0.35 | 동일 |

반감기:

\[
e_t = \phi e_{t-1} + u_t, \qquad HL = \frac{\ln 0.5}{\ln \lvert\phi\rvert}
\]

\(\rho > 0.92\) 는 거의 같은 자산, \(\rho < 0.55\) 는 공통 요인 부족. 둘 다 Out.

형식적 공적분(Johansen)을 Hard로 쓰지 않는다. 코인 스프레드는 짧게 회귀해도 고전적 정상성을 자주 만족하지 않는다.

| 항목 | 배점 | 만점 |

## 7. 페어별 밴드 (운영 원본)

신호는 모든 페어가 같다. **임계만 행마다 다르다.**

- 진입: \(\lvert z\rvert\)가 진입값을 **아래에서 위로 돌파**할 때만. 이미 멀리 가 있는 상태 추격 금지.
- 청산: \(\lvert z\rvert\)가 청산값 아래로 복귀.
- 손절: \(\lvert z\rvert\)가 손절값을 넘은 뒤 **손절지속 시간** 동안 유지, 또는 보유 중 \(z\)가 진입 반대 방향으로 **+1.0** 초과.
- 시간 손절: \(\min(\)최대보유, \(HL \times\) HL배수\()\).
- 반대 플립: **전 페어 금지**. 같은 봉에서 반대 진입하지 않는다.

## 8. 상태기계

| 상태 | 조건 | 행동 |
|---|---|---|
| Flat | Hard 통과 AND burn-in 끝 AND \|z\|가 진입값을 상향 돌파 AND 이벤트 게이트 통과 AND 쿨다운 아님 AND 중복 규칙 통과 | `z>0` → SHORT_SPREAD, `z<0` → LONG_SPREAD. 이 봉 \(\beta\) 고정 |
| In | \|z\| ≤ 청산값 | 전량 청산. 정상 회귀이므로 쿨다운 없음 |
| In | \|z\| ≥ 손절값 지속 h시간 OR 반대 방향 +1.0 OR 시간손절 | 전량 청산. 쿨다운 시작 |
| In | 이벤트 게이트 실패 | 즉시 청산. 쿨다운. 재형성 전까지 Off |
| In | \|Δβ\|/β ≥ 리헤지 임계 | X 다리만 목표 노셔널로 조정 |
| Any | 거래 창 10일 종료 | 전량 청산. 재스크리닝 |

이벤트 게이트 (z와 무관, 즉시 Off):

- 해킹, 체인 스톱, 상장/상장폐지
- 한쪽만의 규제·ETF·소송 헤드라인
- 대규모 언락
- 거래소 해당 심볼 점검·호가 공백

청산 사유 표준값 (로그용):

`EXIT_MEAN` / `STOP_Z` / `STOP_TIME` / `STOP_EVENT` / `STOP_FLIP` / `WINDOW_END`

## 10. 실행 규칙

1. 거래소는 OKX만. 심볼은 `Y-USDT-SWAP`, `X-USDT-SWAP`.
2. 신호는 mark, 주문은 리테일 기본 **다음 봉 시가/지정**. 신호 봉 종가 체결로 백테스트하지 않는다.
3. 양다리를 가능한 한 같은 초에 낸다. 한쪽만 체결되면 즉시 되돌리거나 미체결 다리를 따라간다. 잔여 델타를 들고 가지 않는다.
4. 레버리지 1~2x. isolated 권장.
5. 펀딩 정산 직전에 포지션을 일부러 돌리지 않는다. 다만 한방향 펀딩이 8일을 넘긴 페어는 이미 Hard Out이다.
6. 백테스트는 인과 필터만 사용한다. 스무더 금지.
7. \(\delta, R\), 진입 밴드를 인샘플에서 동시에 돌리지 않는다. 바꾸면 Cover 버전을 1.1로 올린다.
