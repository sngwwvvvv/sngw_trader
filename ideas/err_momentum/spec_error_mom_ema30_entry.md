# 스펙 B — ERROR-MOM 레짐 + 30분 EMA 밴드 엔트리

일봉 ERMOM은 방향 허가만 담당한다. 실제 진입은 30분봉 EMA20/EMA50 리본에서 **밴드 재진입 후 EMA20 재돌파 마감, 다음 봉 시가**로 한다. 스펙 A와 비교해 엔트리 오버레이의 가치를 측정한다.

## 2. ERROR-adjusted momentum 계산 (공통)

원문: David Varadi, *Error-Adjusted Momentum* (2014-07-30). 구현 기준: Systematic Investor (2014-08-01).

입력은 **일봉 수익률만** 사용한다. 30분봉 수익률로 MAE나 ERMOM을 다시 계산하지 않는다.

### 2.1 기호

| 기호 | 정의 |
|---|---|
| \(P_t\) | 일봉 종가 |
| \(r_t\) | 단순 수익률 |
| \(W_f\) | 예측 창. 기본값 10 |
| \(W_e\) | MAE 창. 기본값 10 |
| \(L\) | 모멘텀 창. 기본값 200 |
| \(f_t\) | \(W_f\)일 단순이동평균 수익률 |
| \(e_t\) | 예측오차 |
| \(\mathrm{MAE}_t\) | 평균절대오차 |
| \(\mathrm{ERMOM}_t\) | 오차조정 모멘텀 |

### 2.2 공식

1. 일봉 수익률

\[
r_t = \frac{P_t}{P_{t-1}} - 1
\]

2. \(W_f\)일 평균 수익률을 다음 봉 예측으로 사용

\[
f_t = \mathrm{SMA}(r, W_f)_t
\]

3. 오차는 ‘어제 예측 vs 오늘 실현’. 미래 정보를 쓰지 않는다.

\[
e_t = r_t - f_{t-1}
\]

4. 최근 \(W_e\)개 절대오차의 평균

\[
\mathrm{MAE}_t = \mathrm{SMA}(|e|, W_e)_t
\]

5. 당일 수익률을 MAE로 나눈 뒤 \(L\)일 평균. \(\mathrm{MAE}_t = 0\)이면 해당 봉 `adj_r`는 결측으로 두고 이전 유효값만으로 SMA를 구성한다. 0으로 나누지 않는다.

\[
\mathrm{adj\_r}_t = \frac{r_t}{\mathrm{MAE}_t}, \qquad
\mathrm{ERMOM}_t = \mathrm{SMA}(\mathrm{adj\_r}, L)_t
\]

### 2.3 레짐 정의 (공통)

| 레짐 | 조건 |
|---|---|
| `regime = +1` (롱 허용) | \(\mathrm{ERMOM}_t > 0\) |
| `regime = -1` (숏 허용) | \(\mathrm{ERMOM}_t < 0\) |
| `regime = 0` (신규 진입 금지) | \(\mathrm{ERMOM}_t = 0\) 또는 warm-up 미충족 |

- warm-up: \(r, f, e, \mathrm{MAE}, \mathrm{ERMOM}\)이 모두 유효하려면 최소 \(L + W_f + W_e\) 일봉이 필요하다. 기본 220 거래일 이전에는 포지션 0.
- 레짐은 마감된 일봉에서만 갱신된다. 일중 30분봉이 바뀌어도 ERMOM을 재계산하지 않는다.

## 3. 30분 엔트리 상태머신 (스펙 B 고유)

### 3.1 설계 원칙

- 롱 신규 진입은 \(\mathrm{ERMOM} > 0\) 인 동안만. 숏 신규 진입은 \(\mathrm{ERMOM} < 0\) 인 동안만.
- 밴드 정의는 롱 기준 \([\mathrm{EMA}_{50}, \mathrm{EMA}_{20}]\). \(\mathrm{EMA}_{20} > \mathrm{EMA}_{50}\) 일 때만 롱 밴드가 성립한다.
- 트리거는 밴드에 재진입한 이후 EMA20을 종가로 다시 돌파한 봉이다. 그 다음 30분봉 시가에 진입한다.
- 가점·점수제·비율 기울기는 사용하지 않는다.

### 3.2 30분 지표

| 항목 | 정의 |
|---|---|
| 타임프레임 | 30분 |
| EMA20 | 종가 EMA, span=20 (약 10시간) |
| EMA50 | 종가 EMA, span=50 (약 25시간) |
| 롱 밴드 | \([\mathrm{EMA}_{50}, \mathrm{EMA}_{20}]\), 단 \(\mathrm{EMA}_{20} > \mathrm{EMA}_{50}\) 일 때만 유효 |
| 숏 밴드 | \([\mathrm{EMA}_{20}, \mathrm{EMA}_{50}]\), 단 \(\mathrm{EMA}_{20} < \mathrm{EMA}_{50}\) 일 때만 유효 |
| seed | EMA는 충분한 봉이 쌓인 뒤 사용. 최소 50봉 warm-up |

### 3.3 롱 상태

일봉 `regime == +1` 일 때만 이 기계를 돌린다. regime이 +1이 아니면 롱 셋업을 `L_IDLE`로 리셋하고 롱 신규 주문을 내지 않는다.

| 상태 | 의미 | 전이 조건 |
|---|---|---|
| `L_IDLE` | 셋업 없음 | `regime=+1` 이고 `close > EMA20` 이며 `EMA20 > EMA50` 이면 `L_EXT` |
| `L_EXT` | 밴드 위에서 확장. 되돌림 대기 | `low ≤ EMA20` 이고 `low ≥ EMA50` 이면 `L_PULL`. `close < EMA50` 이거나 `EMA20 ≤ EMA50` 이면 `L_IDLE` |
| `L_PULL` | 밴드 `[EMA50, EMA20]` 재진입 | `close > EMA20` 이면 `L_TRIG`. `close < EMA50` 이거나 `EMA20 ≤ EMA50` 이면 `L_IDLE`. 체류가 `N_pull`봉을 넘으면 `L_IDLE` |
| `L_TRIG` | 재돌파 마감 확정. 주문 대기 | 다음 30분봉 시가에 롱 진입 후 `L_IN`. 시가 전에 regime이 +1이 아니게 되면 주문 취소, `L_IDLE` |
| `L_IN` | 롱 보유 | 청산 조건 충족 시 다음 30분 시가에 청산 후 `L_IDLE` |

- **재진입**: `L_EXT`를 한 번 거친 뒤에야 `L_PULL`로 갈 수 있다. 처음부터 밴드 안에 있던 봉은 트리거가 아니다.
- **터치**: 해당 30분봉 `low`가 밴드와 겹치면 인정 (윅 인정). 종가까지 밴드 안에 들어올 필요는 없다.
- **EMA20 재돌파 마감**: `L_PULL` 이후 허용 체류 안의 봉에서 `close > EMA20`. 그 봉이 트리거 봉이다. 트리거 봉 종가가 아니라 다음 봉 시가에 들어간다.

### 3.4 숏 상태 (거울, 파라미터는 동일 기본값)

일봉 `regime == -1` 일 때만 동작한다.

| 상태 | 의미 | 전이 조건 |
|---|---|---|
| `S_IDLE` | 셋업 없음 | `regime=-1` 이고 `close < EMA20` 이며 `EMA20 < EMA50` 이면 `S_EXT` |
| `S_EXT` | 밴드 아래 확장. 반등 대기 | `high ≥ EMA20` 이고 `high ≤ EMA50` 이면 `S_PULL`. `close > EMA50` 이거나 `EMA20 ≥ EMA50` 이면 `S_IDLE` |
| `S_PULL` | 밴드 `[EMA20, EMA50]` 재진입 | `close < EMA20` 이면 `S_TRIG`. `close > EMA50` 이거나 `EMA20 ≥ EMA50` 이면 `S_IDLE`. 체류 > `N_pull` 이면 `S_IDLE` |
| `S_TRIG` | 재이탈 마감 확정 | 다음 30분 시가에 숏 진입 후 `S_IN`. 직전 regime이 −1이 아니면 취소 |
| `S_IN` | 숏 보유 | 청산 후 `S_IDLE` |

### 3.5 의사코드 (롱)

매 30분봉 마감 후, 이미 마감된 최신 일봉의 ERMOM으로 regime을 읽는다.

```text
if regime != +1:
    cancel long setup
    if long position: flatten at next 30m open
    return

ema20, ema50 = EMA(close, 20), EMA(close, 50)
if not (ema20 > ema50):
    reset to L_IDLE
    return

band = [ema50, ema20]
L_IDLE -> L_EXT  when close > ema20
L_EXT  -> L_PULL when low intersects band
L_PULL -> L_TRIG when close > ema20
L_PULL -> L_IDLE when close < ema50 or bars_in_pull > N_pull
L_TRIG -> enter long at next open; L_IN
```

## 4. 청산 규칙 (스펙 B 고유)

1차 비교에서 손절·목표가 없이 아래만 사용한다.

| 우선 | 조건 | 집행 |
|---|---|---|
| 1 | 일봉 레짐이 포지션 반대가 됨 (롱인데 ERMOM ≤ 0, 숏인데 ERMOM ≥ 0) | 다음 30분봉 시가 전량 청산. 플립 진입은 하지 않음. 반대 방향은 그 방향 상태머신을 처음부터 |
| 2 | 롱 보유 중 30분 `close < EMA50` | 다음 30분 시가 청산. 리본 실패 |
| 2s | 숏 보유 중 30분 `close > EMA50` | 다음 30분 시가 청산 |
| 3 | 롱 보유 중 `EMA20 ≤ EMA50` 로 교차 | 다음 30분 시가 청산 |
| 3s | 숏 보유 중 `EMA20 ≥ EMA50` 로 교차 | 다음 30분 시가 청산 |

레짐 반전 시 즉시 반대 포지션으로 플립하지 않는 것이 스펙 A와의 핵심 차이다. 스펙 A는 플립한다. 스펙 B는 플랫 후 새 셋업을 기다린다.

재진입: 청산 후 반드시 `EXT → PULL → TRIG`를 다시 통과해야 한다. 청산 직후 가격이 이미 EMA20 위에 있다고 바로 재진입하지 않는다.

## 5. 주문 · 보유 제약

- 최대 포지션: −1, 0, +1. 부분 체결이 나면 잔량만 다음 시가에 한 번 더 시도하고, 그래도 안 되면 셋업 취소.
- `L_IN` / `S_IN` 중 추가 트리거는 무시 (피라미딩 없음).
- 롱 셋업과 숏 셋업을 동시에 armed 하지 않는다. regime이 한쪽만 허가한다.
- 일봉이 바뀌는 00:00 UTC 30분봉에서도 규칙은 같다. 다만 그 봉 마감 후 regime이 갱신되면 4절 1번이 우선한다.

## 7. 비교 실험 프로토콜 (공통)

두 스펙의 차이를 엔트리/홀딩 규칙 하나로 제한하기 위해 아래를 고정한다.

### 7.1 고정할 것

- 상품, 일봉 ERMOM 공식, \(W_f=10\), \(W_e=10\), \(L=200\), 일봉 경계(UTC 0)
- 비용 모델: 동일 taker fee, 동일 펀딩 시계열, 동일 슬리피지 bps
- 사이징: 동일 명목 1단위 (또는 동일 변동성 타깃). 한쪽만 레버리지를 올리지 않음
- 초기자본, 기간, 결측 처리, mark 가격 소스

### 7.2 달라야 하는 것

포지션이 열리는 시각, 닫히는 시각, 시장에 머무는 시간뿐이다. 스펙 A는 일봉 레짐 자체를 포지션으로 쓴다. 스펙 B는 일봉 레짐을 허가로만 쓰고 30분 상태머신으로 진입한다.

### 7.3 필수 산출 지표

| 지표 | 정의 | 비교 때 보는 점 |
|---|---|---|
| 순수익 / CAGR | 비용·펀딩 차감 후 | 절대 성과 |
| Sharpe / Sortino | 일간 수익률 기준 | 위험조정 |
| Max DD / 회복일 | 마크투마켓 고점 대비 | 생존 |
| 거래 횟수 / 평균보유 | 왕복 기준 | 턴오버 차이 |
| 시장 체류 비율 | 포지션 ≠ 0 인 봉 비율 | 스펙 B가 현저히 낮아야 정상 |
| 승률 / payoff | 거래 단위 | 엔트리 품질 |
| 롱 vs 숏 | 방향별 CAGR·DD | 비대칭 여부 |
| 비용 기여 | 수수료, 펀딩, 슬리피지 분해 | 30분 엔트리가 비용을 얼마나 쓰는지 |

### 7.4 ablation

- A vs B 전체 비교가 1차
- B에서 레짐 필터를 끄면 (30분 EMA만) 3번째 시리즈. 레짐이 가치를 갖는지 여기서 본다
- \(L \in \{60, 90, 120, 200\}\) 은 두 스펙에 동일하게 적용한 뒤에만 비교
- 손절은 1차에 넣지 않는다. 넣으면 어느 규칙이 성과를 만드는지 분해되지 않는다

## 9. 수락 조건

- 동일한 일봉 데이터에서 스펙 A와 ERMOM 시계열이 일치한다.
- \(\mathrm{ERMOM} > 0\) 이 아닌 구간에 롱 진입 이벤트가 0건이다. \(\mathrm{ERMOM} < 0\) 이 아닌 구간에 숏 진입이 0건이다.
- 트리거 봉 종가가 아니라 다음 30분 시가에 체결된다.
- `L_EXT`를 거치지 않은 채 밴드 안에서 시작된 봉이 트리거가 되지 않는다.
- 레짐 반전 시 플립하지 않고 플랫한다.
