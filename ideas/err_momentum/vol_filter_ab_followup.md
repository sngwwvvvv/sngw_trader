## 후속 작업 큐 (2026-08-31, 미착수)

아래 3개를 **기존 전략(Spec A / Spec B, long-short 그대로)과 비교**해서 테스트한다.

1. **Long-only 변환** — regime=-1 → 숏 대신 플랫. 근거: 숏 레그가 반(反)엣지
   (probe: ERMOM<0 구간 5d fwd +0.12%, 2021년 +11.4% 스퀴즈).
   구현 후보: 전략 config에 `allow_short: bool = True` 추가,
   `regime_target` 뒤에서 -1 → 0 매핑. Spec A/B 각각 적용.
2. **θ 데드존** — θ ∈ {0, 0.25, 0.5} 수준 그리드 (adj_r 스케일 기준 재조정 필요).
   목적: 레짐 플립 잡음/플립 비용 감소. probe 기준 레짐 0 구간이 현재 0건이므로
   θ>0일 때 0(플랫) 구간이 생기는 효과까지 관찰.
3. **벤치마크 명시** — 모든 비교에 Buy&Hold(gross Sharpe ~0.99, 5.4년 기준)를
   같이 표기하고, B&H를 넘지 못하면 오버레이 채택 보류. WF 리포트에
   B&H 라인 추가(동일 기간 daily return 기준)가 가장 싼 구현.

테스트 우선순위: 1 > 2 > 3 (3은 리포트 개선이라 즉시 가능, 1·2는 WF 재실행 필요).
WF 설정은 `logs/ErrMomEma30Entry/20260831-080525/` 실행과 동일
(2020-08-20 ~ 2023-01-01, IS 6 / OOS 3 / holdout 6, warmup 225, min_trades 15).

## 후속 작업 결과 (2026-08-31, 완료)

공통: WF 설정 동일(2020-08-20~2023-01-01, IS6/OOS3/holdout6, warmup 225,
min_trades 15). θ 후보는 카탈로그 분포 probe로 재조정 — 실제 ERMOM 스케일:
일봉(10,10,200) q50=+0.08/q90=+0.27/q99=+0.38 → {0, 0.1, 0.2};
4h(5,5,48)도 {0, 0.1, 0.2}가 flat 0/40/71%로 유효. 문서의 0.5는 전 구간 플랫.

### 1. Long-only 변환 (`allow_short`, -1→0 매핑) — 채택 (개선이지만 엣지는 아님)

- Spec A (`logs/ErrMomentumRegime/20260831-092012` A/B, `092740` long-only OOS):
  - IS Sharpe: long-only가 5개 윈도우 전부 우위
    (0.380 vs 0.251, 0.302 vs 0.195, 0.065 vs 0.010, 0.051 vs -0.111, -0.060 vs -0.051)
  - stitched OOS: -82.38(n=178) → **-41.24(n=86), 손실 절반**
  - holdout: -23.90(n=114) → **-11.38(n=53)**
- Spec B (`logs/ErrMomEma30Entry/20260831-092015`): 숏 거래가 거의 없음
  (윈도우별 IS 거래수 차이 0~4건, W0~W2는 0건). stitched OOS -51.87 ≈ 기존 -51.15.
  holdout 86거래는 **전부 숏** → long-only holdout은 거래 0건(레짐<0 지속).
- 주의: `select_best`는 이웃-중앙값 스무딩이라 2값 축 A/B에서는 항상 먼저 온 값이
  선택됨(타이). 비교는 그리드 행/단일 조합 OOS로 판단할 것.
- 결론: 숏 레그는 반(反)엣지라는 probe 예측이 백테스트로 확인됨. 다만 long-only도
  여전히 음수 — churn이 남고(거래당 expectancy ≈ -0.2 USDT ≈ 수수료) 엣지 없음.

### 2. θ 데드존 — 기각 (일관된 개선 없음)

- Spec A (`logs/ErrMomentumRegime/20260831-093427`, long-only 고정):
  W0만 θ=0.2 선호(0.448), W2/W4는 θ=0이 최선, W3는 θ=0.1. stitched OOS -40.80
  (θ=0 단독 -41.24와 동일 수준), holdout 동일 -11.38.
- Spec B (`logs/ErrMomEma30Entry/20260831-093429`, long-only 고정, θ×tf 9조합):
  θ>0이면 W3/W4에서 거래 붕괴(n=0~1, min_trades 미달로 θ=0 회귀). stitched OOS
  -63.26(혼합 선택), holdout 0거래. 데드존이 전략을 꺼버림.
- 결론: θ 데드존은 플립 비용을 줄이는 게 아니라 활동 자체를 죽임. 채택 근거 없음.

### 3. B&H 벤치마크 — 구현 완료 (`walk_forward.py`의 `bh_metrics`)

- WF 리포트/서머리에 `oos_benchmark`·`holdout_benchmark`(윈도우별 `oos_benchmark`)
  자동 산출: 총수익 + 일별수익 연율화 Sharpe. 카탈로그 일봉 기준 [start, end).
- 본 WF 기준 수치: OOS 구간(2020-08~2022-07) B&H **+68.2%, Sharpe 0.75**,
  holdout(2022-07~12) B&H **-14.2%, Sharpe -0.26**.
- 판정: 모든 변형(long/short, θ)이 OOS에서 B&H에 크게 미달 → **오버레이/변형 채택
  보류 유지**. 신호 자체(일봉 모멘텀 구조)를 바꾸지 않는 한 전략 기각이 합리적.

### 종합

손실이 절반으로 줄지만 여전히 B&H 미달·절대 수익 음수. 다음 단계는 오버레이가
아니라 신호 재설계(모멘텀 정의/리밸런스 주기) 또는 전략 보류.
