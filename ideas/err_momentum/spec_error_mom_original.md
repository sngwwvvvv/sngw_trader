# 스펙 A — ERROR-adjusted Momentum 원문형

일봉 ERMOM 부호를 곧 포지션으로 사용한다. 30분봉 엔트리 규칙은 없다. 스펙 B와의 비교에서 벤치마크 역할을 한다.

## 2. ERROR-adjusted momentum 계산 (공통)

원문: David Varadi, *Error-Adjusted Momentum* (2014-07-30). 구현 기준: Systematic Investor (2014-08-01).

입력은 **일봉 수익률만** 사용한다. 30분봉 수익률로 MAE나 ERMOM을 다시 계산하지 않는다.

### 2.1 기호

| 기호 | 정의 |
|---|---|
| \(P_t\) | 일봉 종가 |
| \(r_t\) | 단순 수익률 |
| \(W_f\) | 예측 창. 기본값 10 |
| \(W_e\) | MAE 창. 기본값 10 |
| \(L\) | 모멘텀 창. 기본값 200 |
| \(f_t\) | \(W_f\)일 단순이동평균 수익률 |
| \(e_t\) | 예측오차 |
| \(\mathrm{MAE}_t\) | 평균절대오차 |
| \(\mathrm{ERMOM}_t\) | 오차조정 모멘텀 |

### 2.2 공식

1. 일봉 수익률

\[
r_t = \frac{P_t}{P_{t-1}} - 1
\]

2. \(W_f\)일 평균 수익률을 다음 봉 예측으로 사용

\[
f_t = \mathrm{SMA}(r, W_f)_t
\]

3. 오차는 ‘어제 예측 vs 오늘 실현’. 미래 정보를 쓰지 않는다.

\[
e_t = r_t - f_{t-1}
\]

4. 최근 \(W_e\)개 절대오차의 평균

\[
\mathrm{MAE}_t = \mathrm{SMA}(|e|, W_e)_t
\]

5. 당일 수익률을 MAE로 나눈 뒤 \(L\)일 평균. \(\mathrm{MAE}_t = 0\)이면 해당 봉 `adj_r`는 결측으로 두고 이전 유효값만으로 SMA를 구성한다. 0으로 나누지 않는다.

\[
\mathrm{adj\_r}_t = \frac{r_t}{\mathrm{MAE}_t}, \qquad
\mathrm{ERMOM}_t = \mathrm{SMA}(\mathrm{adj\_r}, L)_t
\]

### 2.3 레짐 정의 (공통)

| 레짐 | 조건 |
|---|---|
| `regime = +1` (롱 허용) | \(\mathrm{ERMOM}_t > 0\) |
| `regime = -1` (숏 허용) | \(\mathrm{ERMOM}_t < 0\) |
| `regime = 0` (신규 진입 금지) | \(\mathrm{ERMOM}_t = 0\) 또는 warm-up 미충족 |

- warm-up: \(r, f, e, \mathrm{MAE}, \mathrm{ERMOM}\)이 모두 유효하려면 최소 \(L + W_f + W_e\) 일봉이 필요하다. 기본 220 거래일 이전에는 포지션 0.
- 레짐은 마감된 일봉에서만 갱신된다. 일중 30분봉이 바뀌어도 ERMOM을 재계산하지 않는다.

## 3. 포지션 규칙 (스펙 A 고유)

### 3.1 핵심

레짐이 곧 포지션이다. 별도의 진입 트리거, 되돌림, EMA 조건이 없다.

| 조건 | 행동 |
|---|---|
| \(\mathrm{ERMOM}_t > 0\) | 다음 일봉 시가에 롱 +1. 이미 롱이면 유지 |
| \(\mathrm{ERMOM}_t < 0\) | 다음 일봉 시가에 숏 −1. 이미 숏이면 유지 |
| \(\mathrm{ERMOM}_t = 0\) 또는 warm-up | 다음 일봉 시가에 플랫 0 |

### 3.2 상태 전이

| 현재 | 새 레짐 | 다음 일봉 시가 행동 |
|---|---|---|
| FLAT | +1 | 롱 진입 |
| FLAT | −1 | 숏 진입 |
| LONG | +1 | 유지 |
| LONG | −1 | 롱 청산 후 숏 진입 (플립) |
| LONG | 0 | 롱 청산 |
| SHORT | −1 | 유지 |
| SHORT | +1 | 숏 청산 후 롱 진입 (플립) |
| SHORT | 0 | 숏 청산 |

플립은 한 시가에서 청산과 진입을 연속 처리한다. 구현은 reduce-only 청산 후 반대 주문, 또는 단일 net 주문. 비용은 왕복으로 계산한다.

### 3.3 사용하지 않는 것

- 30분봉, EMA20, EMA50, 밴드, 되돌림, 재돌파
- 임계값 \(\theta\). 원문과 동일하게 0을 사용. \(\theta \neq 0\)은 후속 실험
- 신호 발생 후 지정가 대기. 항상 다음 일봉 시가

## 4. 진입 · 청산 타이밍

| 이벤트 | 기준 봉 | 집행 |
|---|---|---|
| ERMOM 계산 | 일봉 \(t\) 종가 | 계산만. 주문 없음 |
| 진입 / 플립 / 청산 | 일봉 \(t\) 종가 확정 후 | 일봉 \(t+1\) 시가 |
| 평가손익 | 보유 중 모든 일봉 종가 | 마크 가격 |

일봉 시가가 결측이면 다음 유효 시가로 미룬다. 미체결 상태를 건너뛰어 그다음 봉 종가로 체결하지 않는다.

## 5. 리스크 · 보유

- 전략 청산은 레짐 반전 또는 0 전환뿐이다.
- 원문과 같이 손절·목표가는 없다. 비교 1차에서 추가하지 않는다.
- 항상 시장에 머무는 always-in 전략이다 (warm-up과 레짐 0 제외).
- 펀딩은 포지션이 열린 동안 OKX 정산 주기대로 반영한다.

## 7. 비교 실험 프로토콜 (공통)

두 스펙의 차이를 엔트리/홀딩 규칙 하나로 제한하기 위해 아래를 고정한다.

### 7.1 고정할 것

- 상품, 일봉 ERMOM 공식, \(W_f=10\), \(W_e=10\), \(L=200\), 일봉 경계(UTC 0)
- 비용 모델: 동일 taker fee, 동일 펀딩 시계열, 동일 슬리피지 bps
- 사이징: 동일 명목 1단위 (또는 동일 변동성 타깃). 한쪽만 레버리지를 올리지 않음
- 초기자본, 기간, 결측 처리, mark 가격 소스

### 7.2 달라야 하는 것

포지션이 열리는 시각, 닫히는 시각, 시장에 머무는 시간뿐이다. 스펙 A는 일봉 레짐 자체를 포지션으로 쓴다. 스펙 B는 일봉 레짐을 허가로만 쓰고 30분 상태머신으로 진입한다.

### 7.3 필수 산출 지표

| 지표 | 정의 | 비교 때 보는 점 |
|---|---|---|
| 순수익 / CAGR | 비용·펀딩 차감 후 | 절대 성과 |
| Sharpe / Sortino | 일간 수익률 기준 | 위험조정 |
| Max DD / 회복일 | 마크투마켓 고점 대비 | 생존 |
| 거래 횟수 / 평균보유 | 왕복 기준 | 턴오버 차이 |
| 시장 체류 비율 | 포지션 ≠ 0 인 봉 비율 | 스펙 B가 현저히 낮아야 정상 |
| 승률 / payoff | 거래 단위 | 엔트리 품질 |
| 롱 vs 숏 | 방향별 CAGR·DD | 비대칭 여부 |
| 비용 기여 | 수수료, 펀딩, 슬리피지 분해 | 30분 엔트리가 비용을 얼마나 쓰는지 |

### 7.4 ablation

- A vs B 전체 비교가 1차
- B에서 레짐 필터를 끄면 (30분 EMA만) 3번째 시리즈. 레짐이 가치를 갖는지 여기서 본다
- \(L \in \{60, 90, 120, 200\}\) 은 두 스펙에 동일하게 적용한 뒤에만 비교
- 손절은 1차에 넣지 않는다. 넣으면 어느 규칙이 성과를 만드는지 분해되지 않는다

## 9. 수락 조건

- 코드가 2.2 공식을 봉 단위로 재현하고, \(f_t\)와 \(e_t\) 사이에 1봉 래그가 있다.
